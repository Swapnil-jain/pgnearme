# PGNear.me

**Live at [pgnear.me](https://pgnear.me)**

PGNear.me set out to solve the broken PG (Paying Guest) hunting experience in India. We ran a survey across 725 people to validate the problem, collected 539 detailed responses, and this site now serves as a public archive of those findings.

## What We Did

- Built a landing page to capture interest and run a 5-question survey about PG hunting pain points
- Collected **725 signups** and **539 completed surveys** (74% completion rate) between April and August 2025
- Validated that the PG discovery market has real, widespread problems — and that people are willing to pay for solutions

## What We Found

| Finding | Detail |
|---------|--------|
| **Core audience** | 56% aged 18-24, 90% under 30 |
| **#1 frustration** | Fake or unavailable reviews (23%) |
| **Discovery is broken** | 39% are first-time PG seekers with no idea where to start |
| **Willingness to pay** | 61% said "Yes" or "Maybe" to paying Rs.99 for instant visit scheduling |
| **Pain is systemic** | Top 5 frustrations are within 22% of each other — no single fix |
| **Engagement was real** | 74% survey completion vs ~30% industry average |

## What's Here Now

The site has been closed due to internal reasons. The survey is complete and the database has been paused. This codebase now serves as:

1. **A public data showcase** — interactive charts and insights from the survey data, with no sensitive information
2. **The original problem/solution framing** — the "Problem" and "How We Help" sections remain for context
3. **A fully static Next.js site** — no backend, no database, no API routes. Just the data and the story.

## Tech Stack

- **Next.js 15** (static export)
- **React 18** + TypeScript
- **Recharts** for data visualization
- **Tailwind CSS** + Radix UI for styling
- **Vercel** for hosting
